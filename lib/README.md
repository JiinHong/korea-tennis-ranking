# lib 폴더 안내

`app/api`는 브라우저에서 들어온 HTTP 요청을 받고 응답을 반환합니다.
`lib`는 API, 화면, 관리자 기능에서 함께 사용하는 규칙과 데이터 접근 코드를 보관합니다.

## 폴더별 역할

- `admin`: 관리자 권한 정책과 수동 순위 조정 규칙
- `analytics`: Amplitude 초기화와 내부 사용자 트래픽 구분
- `campusRanking`: 대학별 단식 랭킹 설정, 운영 규칙, 통계 및 선수 상세 데이터
- `googleSheets`: 기존 Google Sheets 데이터 읽기 기능
- `nationalRanking`: 전국 대학 테니스 동아리 대회 결과와 랭킹 계산
- `supabase`: Supabase 연결, 조회 및 데이터 변경
  - `admin`: 관리자용 선수·경기 조회와 변경
  - `monthly`: 월간 정산과 자동화 상태
  - `seed`: 초기 데이터를 넣기 위한 계획과 SQL 생성

## 코드가 실행되는 흐름

1. `app/api` 또는 화면이 요청을 받습니다.
2. 필요한 기능을 `lib`에서 가져와 실행합니다.
3. `lib`가 운영 규칙을 적용하고 Google Sheets 또는 Supabase에서 데이터를 읽고 씁니다.
4. 결과가 API 응답이나 화면 데이터로 반환됩니다.

새 파일은 기술 이름보다 담당 업무를 기준으로 가장 가까운 폴더에 둡니다.

## `app`과 구분하는 기준

- 요청 주소와 HTTP 상태 코드는 `app/api`가 책임집니다.
- 화면에서만 쓰는 상태와 표현은 해당 화면의 `_components` 또는 `_lib`가 책임집니다.
- 화면과 API 양쪽에서 다시 쓸 수 있는 계산, 검증, 저장소 접근만 `lib`에 둡니다.
- `lib`의 파일은 React 화면이나 특정 URL을 직접 알지 않도록 유지합니다.
