# Campus Ranking Engagement Design

## Goal

캠퍼스 단식 랭킹에서 최근 대회 성적 페이지로 자연스럽게 이동할 수 있게 하고, 현재 순위가 지난주보다 얼마나 변했는지 일관된 기준으로 보여준다.

## Approved Information Order

1. 현재 TOP 3
2. 최근 30일 기록
3. 최근 대회 결과 안내
4. 전체 랭킹

하위 순위 선수의 도전 범위를 바꾸는 운영 규칙은 이번 작업에 포함하지 않는다.

## Tournament Result Notice

- 최근 30일 기록과 전체 랭킹 사이에 배치한다.
- 안내 문구는 `2026 하늘내린인제 결과가 반영됐어요`로 통일한다.
- 서울과기대 링크는 `느티나무 대회 기록 확인하기 →`로 표시한다.
- PETC 링크는 `PETC 대회 기록 확인하기 →`로 표시한다.
- 작은 붉은 포인트와 옅은 배경을 사용하되 별도의 큰 카드처럼 보이지 않게 한다.

## Weekly Rank Movement

- 기준 시점은 매주 월요일 00:00 KST다.
- 월요일 기준 순위에서 현재 순위를 뺀 값을 변동 폭으로 사용한다.
- 양수는 파란색 `▲ n`, 음수는 빨간색 `▼ n`, 0은 흐린 `–`로 표시한다.
- 순위 변동은 전체 랭킹의 순위 번호 옆에 표시한다.
- 페이지가 열릴 때마다 기준값을 바꾸지 않고, DB에 저장된 주간 스냅샷과 비교한다.
- 스냅샷이 아직 없는 선수는 변동 없음으로 처리한다.

## Data Model

`weekly_ranking_snapshots`는 시즌, 선수, 기준 주차별 순위를 저장한다.

- `season_id`: 시즌
- `player_id`: 선수
- `week_start`: KST 월요일 날짜
- `rank`: 해당 시점 순위

매주 월요일 00:00 KST에 현재 시즌 순위를 한 번 저장한다. 최초 배포 시에는 현재 주의 기준값을 한 번 생성한다.

## Accessibility And Analytics

- 변동 표시는 `지난주보다 n계단 상승/하락`, `지난주와 동일`이라는 접근성 이름을 제공한다.
- 대회 결과 링크는 기존 캠퍼스 성적 페이지의 성별 문맥을 유지한다.
- 링크 클릭은 기존 캠퍼스 대회 기록 이동 이벤트에 `source: "ranking_result_update"`를 기록한다.

## Verification

- KST 일요일과 월요일 경계 계산을 단위 테스트한다.
- 스냅샷과 현재 순위의 차이를 저장소 테스트로 검증한다.
- 컴포넌트 테스트에서 안내 문구, 링크, 섹션 순서, 상승·하락·동일 표시를 검증한다.
- 모바일과 데스크톱 캡처에서 간격, 글자 크기, 순위 행 정렬을 확인한다.
