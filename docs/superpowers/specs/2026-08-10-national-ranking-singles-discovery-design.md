# 전국 랭킹 단식 랭킹 발견성 개선 설계

작성일: 2026-08-10

## 1. 목표

전국 대학 랭킹 페이지(`/`)에서 사용자가 동아리 행을 눌러 대회 성적을 확인할 수 있다는 사실을 명확히 알리고, 실제 단식 랭킹을 운영하는 동아리에서는 해당 화면을 자연스럽게 발견하도록 한다.

전국 랭킹이 페이지의 주인공이라는 현재 제품 방향을 유지한다. 단식 랭킹 홍보 배너, 대학 검색, 반복적인 도입 문의 버튼은 추가하지 않는다.

## 2. 적용 범위

이번 작업은 전국 대학 랭킹 페이지와 그 페이지가 직접 사용하는 컴포넌트에만 적용한다.

- `app/page.tsx`
- `app/_components/national-ranking/NationalRankingTable.tsx`
- `app/_components/national-ranking/NationalRankingExpandedResults.tsx`
- 위 컴포넌트의 테스트와 `app/globals.css`

다음 화면과 기능은 변경하지 않는다.

- 학교별 전체 대회 성적 페이지 `/clubs/[clubSlug]`
- 서울과기대와 PETC 단식 랭킹 페이지 `/seoultech`, `/petc`
- 단식 랭킹 운영 규칙, 경기 입력, 관리자 기능
- 검색 기능과 도입 문의 흐름
- 푸터와 테마 토글

## 3. 헤더 문구

첫 화면은 공유글 같은 개인적인 말투보다 서비스의 데이터 범위를 간결하게 설명한다.

- 제목은 `전국 대학 테니스 동아리 랭킹`을 유지한다.
- 설명은 기존 문구인 `최근 3년간 6개 대학 테니스 대회 성적을 반영한 랭킹입니다.`로 복원한다.
- 이어서 반영 대회 목록을 보여준다.
- `랭킹 계산 방식 보기` 링크는 유지한다.

## 4. 랭킹 행 발견성

랭킹 제목 영역 오른쪽의 기존 왕관 안내는 유지한다. 별도의 사용 안내 문구는 추가하지 않는다.

표는 `순위 / 동아리 / 점수`의 세 열만 사용한다. 점수 셀 안에서 점수 오른쪽에 펼치기 상태 화살표를 배치한다.

- 데스크톱과 모바일 모두 `성적` 열 제목과 `성적 보기`, `성적 접기` 문구를 표시하지 않는다.
- 닫힘 상태는 오른쪽 방향 화살표, 열림 상태는 아래 방향 화살표만 표시한다.
- 점수와 화살표는 하나의 점수 셀 안에 가까이 배치한다.
- 실제 접근 가능한 컨트롤은 기존 disclosure 버튼과 `aria-expanded`를 유지한다.
- 행 전체 클릭 동작과 왕관 툴팁 클릭 예외를 유지한다.

## 5. 단식 랭킹 운영 배지

단식 랭킹이 연결된 다음 두 동아리에만 `단식 랭킹 운영 중` 배지를 표시한다.

- `seoultech-neutinamu` → `/seoultech`
- `korea-petc` → `/petc`

배지 위치는 화면 폭에 따라 다르다.

- 데스크톱: 동아리명 바로 오른쪽
- 모바일: 학교명 바로 오른쪽

배지는 작은 상태 라벨이며 클릭 요소가 아니다. 기존 학교명, 동아리명, 왕관 표시를 밀어내거나 겹치지 않아야 한다.

## 6. 펼친 성적 영역

기존 최고 성적 세 건과 애니메이션을 유지한다.

하단 액션은 박스 없는 텍스트 링크로 표시하며 밑줄을 사용하지 않는다.

- 왼쪽 하단: `전체 성적 보기`
- 오른쪽 하단: `단식 랭킹 보기` — 단식 랭킹 운영 동아리에만 표시

`단식 랭킹 보기` 링크는 현재 선택한 부문을 `fromGender` 쿼리로 전달한다.

- 서울과기대 예: `/seoultech?fromGender=men`
- PETC 예: `/petc?fromGender=women`

단식 랭킹을 운영하지 않는 동아리는 기존처럼 `전체 성적 보기`만 표시한다.

## 7. 분석 이벤트

전국 랭킹 미리보기에서 `단식 랭킹 보기`를 누르면 기존 퍼널과 호환되는 `Campus Ranking Link Clicked` 이벤트를 기록한다.

- `source`: `national_ranking_preview`
- `club_slug`: 전국 랭킹 동아리 슬러그
- `campus_club_slug`: `seoultech` 또는 `petc`
- `division`: 현재 선택된 랭킹 부문

기존 `National Club Preview Opened`와 `National Club Results Opened` 이벤트는 유지한다.

## 8. 반응형·테마 요구사항

- 390px 모바일에서 학교명, 운영 배지, 점수, 화살표가 가로로 잘리지 않아야 한다.
- 데스크톱과 모바일 모두 점수와 화살표가 한 덩어리로 읽혀야 한다.
- 라이트·다크 모드 모두 배지, 링크, 행 hover, 펼친 배경의 대비가 자연스러워야 한다.
- hover 시 흰색 배경으로 바뀌는 회귀가 없어야 한다.
- 링크의 최소 터치 영역은 모바일에서 44px 높이를 확보한다.
- `prefers-reduced-motion`에서는 기존 펼치기 애니메이션 비활성화를 유지한다.

## 9. 테스트와 검수

기능 변경은 TDD로 진행한다.

자동 테스트는 다음을 확인한다.

- 운영 동아리에만 `단식 랭킹 운영 중` 배지가 표시된다.
- 운영 동아리의 펼친 영역에 두 링크가 정확한 이름과 URL로 표시된다.
- 미운영 동아리에는 `단식 랭킹 보기`가 나타나지 않는다.
- 현재 부문이 `fromGender`에 전달된다.
- 단식 랭킹 링크 클릭 분석 이벤트가 기록된다.
- 표가 세 열 구조이고 빈 상태와 상세 행의 `colSpan`이 3으로 일치한다.
- 점수 셀 안에 상태 문구 없이 화살표만 표시된다.
- 기존 행 펼치기, 왕관, 부문 변경 테스트가 계속 통과한다.

브라우저 검수는 다음 조합에서 직접 수행한다.

- 데스크톱 라이트
- 데스크톱 다크
- 모바일 라이트
- 모바일 다크

각 조합에서 닫힌 행, 열린 운영 동아리 행, 열린 미운영 동아리 행, hover와 키보드 포커스를 확인한다.

## 10. 완료 기준

- 로컬 시안에서 승인된 전국 랭킹 화면과 실제 구현의 구조 및 문구가 일치한다.
- 학교별 대회 성적 페이지와 단식 랭킹 페이지에는 변경이 없다.
- 관련 자동 테스트와 전체 프로젝트 검증이 통과한다.
- 모바일·데스크톱, 라이트·다크 브라우저 검수가 완료된다.
- 구현 변경을 별도 커밋으로 만들고 원격 `main`에 푸시한다.
