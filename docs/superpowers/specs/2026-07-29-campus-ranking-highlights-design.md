# Campus Ranking Highlights Design

## Goal

캠퍼스 단식 랭킹 첫 화면에서 순위와 최근 활동을 빠르게 파악하고, 전체 랭킹까지 도달하는 스크롤을 줄인다.

## Approved Information Order

1. 기존 학교 헤더와 랭킹 요약
2. 현재 TOP 3
3. 최근 30일 기록
4. 전체 랭킹

홈 화면의 최근 경기 카드와 별도 활동 피드는 제거한다. 전체 경기 기록은 `전체 랭킹` 제목 오른쪽의 `최근 경기 보기 →` 링크로 이동한다.

## Current TOP 3

- 현재 순위 1~3위 선수를 사용한다.
- 화면 배치는 2위, 1위, 3위 순서다.
- 1위는 가운데에서 조금 더 크게 표시한다.
- 순위 번호와 하단 선에 금, 은, 동 색상을 사용한다.
- 각 선수의 이름과 현재 시즌 승패를 표시한다.
- 선수 영역을 누르면 해당 선수 상세 페이지로 이동한다.

## Recent 30 Days

현재 시즌 경기 중 오늘을 포함한 최근 30일 범위의 경기만 집계한다.

- 최다 출전: 도전자 또는 방어자로 출전한 횟수
- 최다 승리: 승자로 기록된 횟수
- 최다 방어: 방어자로 출전해 승리한 횟수

동률이면 현재 순위가 높은 선수를 우선하고, 순위까지 같으면 이름순으로 정한다. 집계할 수 있는 최근 경기가 없으면 이 섹션은 표시하지 않는다.

## Visual Direction

- TOP 3와 최근 30일 기록은 각각 하나의 흰색 섹션으로 구분한다.
- 섹션 안에 카드가 중첩된 모양은 만들지 않는다.
- 최근 30일 기록은 `항목 / 선수 / 수치`의 세로 3행 구조로 표시한다.
- 전체 랭킹 제목과 최근 경기 링크는 한 행에 정렬한다.
- 모바일에서도 시상대 3명을 한 행에 유지하고, 글자와 수치가 겹치지 않도록 고정 그리드를 사용한다.

## Analytics And Accessibility

- TOP 3 선수 상세 이동은 기존 `Player Profile Opened` 이벤트에 `source: "top_three"`를 기록한다.
- 최근 경기 이동은 `Campus Match History Opened` 이벤트에 `source: "ranking_header"`를 기록한다.
- 각 섹션과 링크에는 한국어 접근성 이름을 제공한다.

## Verification

- 최근 30일 경계, 출전·승리·방어 집계, 동률 우선순위를 단위 테스트한다.
- 컴포넌트 테스트에서 새 섹션 순서, 기존 최근 경기·활동 피드 제거, 최근 경기 링크를 검증한다.
- 데스크톱과 모바일 브라우저 캡처로 정렬, 간격, 오버플로를 확인한다.
