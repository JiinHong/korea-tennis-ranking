# Player Detail Open Layout Design

## Goal

선수 상세 페이지를 중첩 카드 중심 화면에서 여백과 구분선으로 이어지는 열린 기록 페이지로 바꾼다. 메인 랭킹 페이지와 같은 시각 언어를 사용하면서 선수의 통산 기록, 시즌별 전적, 상대별 전적, 최근 경기를 빠르게 훑을 수 있어야 한다.

## Information Order

1. 기존 뒤로가기와 `선수 상세` 헤더
2. 현재 순위, 선수 이름, 통산 승패
3. 통산 경기, 승률, 방어 성공, 도전 성공
4. 시즌별 전적과 상대별 전적
5. 최근 경기

데이터, 통계 계산, 링크, 분석 이벤트는 그대로 유지한다.

## Visual Direction

- 선수 상세 콘텐츠를 감싸는 큰 카드와 그림자를 제거한다.
- 통계는 별도 카드 네 개가 아니라 하나의 열린 4열 요약 행으로 표시한다.
- 시즌별 전적, 상대별 전적, 최근 경기는 배경 상자 없이 제목과 가로 구분선으로 구획한다.
- 각 기록 행도 카드 대신 얇은 가로선 목록으로 표시한다.
- 최근 경기의 `W`, `L`은 현재처럼 파란색과 빨간색 글자만 사용한다.
- 점수는 알약 모양 배경을 제거하고 일반 텍스트로 표시한다.
- 현재 순위는 부드러운 배경 상자를 제거하고 빨간 텍스트로만 강조한다.

## Responsive Behavior

- 데스크톱에서는 시즌별 전적과 상대별 전적을 두 열로 배치한다.
- 모바일에서는 두 섹션을 세로로 배치한다.
- 통계 요약은 모바일에서 2열 2행으로 바뀌며 내부 구분선만 사용한다.
- 기록 행은 좁은 화면에서도 이름과 수치가 겹치지 않도록 유연한 그리드를 유지한다.

## Accessibility And Interaction

- 기존 영역 이름과 제목 구조를 유지한다.
- 기록 목록의 의미와 선수 상세 뒤로가기를 유지한다.
- 시각 변경만으로 데이터나 탐색 동작이 달라지지 않아야 한다.

## Verification

- CSS 테스트로 큰 패널, 통계, 세부 섹션, 기록 행, 점수 배경이 제거되었는지 검증한다.
- 기존 선수 상세 컴포넌트 테스트로 데이터와 링크가 유지되는지 검증한다.
- 모바일과 데스크톱 캡처로 여백, 구분선, 텍스트 겹침을 확인한다.
