# 캠퍼스 랭킹 시즌 맥락 표시 설계

## 목표

전국 랭킹의 단식 랭킹 카드와 느티나무 랭킹 화면에서 누적 경기 규모와 현재 시즌을 간결하게 알린다. 전체 랭킹의 최근 5경기에는 현재 시즌 결과를 우선 유지하고, 남는 빈칸에만 과거 시즌 결과를 흐리게 표시한다.

## 표시 규칙

- 전국 랭킹의 고려대 PETC·서울과기대 느티나무 카드에는 실제 확정 경기의 누적 합계를 `누적 N경기`로 표시한다.
- 두 카드의 오른쪽 이동 표시는 문자 화살표 `→` 대신 선형 꺾쇠 아이콘을 사용한다.
- 캠퍼스 랭킹 상단의 현재 경기 수에는 현재 시즌 이름을 함께 표시한다.
- 과거 시즌이 있는 동아리는 현재 시즌 통계 아래에 시즌별 확정 경기 수를 최신 시즌부터 작고 흐린 한 줄로 표시한다.
- 과거 시즌이 없는 동아리는 과거 시즌 요약 줄을 렌더링하지 않는다.
- 전체 랭킹의 각 선수 행 오른쪽 끝에는 작은 선형 꺾쇠를 표시해 상세 페이지로 이동할 수 있는 행임을 알린다.

## 최근 5경기 규칙

- 현재 시즌 결과는 기존과 동일하게 최대 5개를 선명하게 표시한다.
- 과거 시즌 결과는 `5 - 현재 시즌 결과 수`만큼만 보충한다.
- 과거 시즌 결과는 날짜 기준 최신 기록부터 선택하되, 화면에서는 오래된 결과가 왼쪽, 최신 결과가 오른쪽에 오도록 배치한다.
- 과거 시즌 기록이 부족하면 남은 칸은 빈 원으로 둔다.
- 현재 시즌 결과가 5개이면 과거 결과는 표시하지 않는다.
- 과거 결과도 승리는 초록색 체크, 패배는 빨간색 X의 원형 아이콘을 사용하되 약 40% 농도로 흐리게 표현한다.
- 과거 결과 아이콘은 마우스 호버와 키보드 포커스에서 `시즌2 · 승리`처럼 시즌과 결과를 알려주는 툴팁을 표시한다. 터치와 스크린리더에서도 같은 정보를 확인할 수 있어야 한다.
- 현재 시즌 승·패·경기 수와 최근 경기 날짜는 현재 시즌 기준을 유지한다.

## 데이터 흐름

- 기존 캠퍼스 랭킹 조회가 이미 제공하는 현재 경기와 과거 경기로 시즌별 경기 수와 과거 최근 결과를 계산한다.
- 데이터베이스 스키마나 저장 데이터는 변경하지 않는다.
- 전국 랭킹 카드용 누적 경기 수는 두 동아리의 시즌별 확정 경기 수 합계에서 계산하고 캐시한다.
- 카드용 통계 조회가 실패해도 전국 랭킹 자체는 유지하며, 해당 카드의 누적 경기 문구만 생략한다.

## 검증

- 현재 시즌 결과가 과거 결과에 밀리지 않는 경우를 테스트한다.
- 과거 결과가 없는 선수의 빈칸이 유지되는 경우를 테스트한다.
- 과거 결과의 시즌·승패 툴팁과 접근성 이름을 테스트한다.
- 시즌별 경기 수와 누적 경기 수 계산을 테스트한다.
- 모바일·데스크톱, 라이트·다크 모드에서 글자 대비와 줄바꿈, 꺾쇠 정렬, 과거 결과의 흐림 정도를 직접 확인한다.
