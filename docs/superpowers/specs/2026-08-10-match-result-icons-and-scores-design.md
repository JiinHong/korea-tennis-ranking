# 경기 결과 아이콘 및 세로 점수 표시 설계

작성일: 2026-08-10

## 1. 목표

단식 랭킹 화면 전반의 `W`와 `L` 문자를 직관적인 체크·X 아이콘으로 교체한다. 전체 경기 기록은 ATP 경기 목록처럼 두 선수를 세로로 정렬하고 각 선수의 점수를 같은 줄 오른쪽에 배치해 결과를 빠르게 읽을 수 있게 한다.

## 2. 적용 범위

다음 세 화면을 변경한다.

- `/{club}/matches`: 전체 경기 기록
- `/{club}`: 메인 단식 랭킹의 최근 5경기
- `/{club}/players/{player}`: 선수 상세의 최근 경기

서울과기대와 PETC는 같은 공용 컴포넌트와 스타일을 사용하므로 동일하게 적용한다. 경기 입력, 랭킹 계산, 승패 데이터, 관리자 화면은 변경하지 않는다.

## 3. 아이콘 구현 방식

프로젝트가 이미 사용하는 `lucide-react`의 `Check`와 `X` 아이콘을 사용한다.

- 글꼴에 따라 모양이 달라지는 유니코드 문자보다 작은 화면에서 선 굵기와 정렬이 안정적이다.
- CSS 의사 요소로 도형을 직접 그리는 구현보다 의미가 명확하고 유지보수가 쉽다.
- 장식 아이콘은 `aria-hidden="true"`로 숨기고, 결과를 포함하는 요소에 한국어 접근성 이름을 제공한다.

## 4. 전체 경기 기록

각 경기 항목은 날짜·방어 결과 헤더 아래에 두 선수 행을 세로로 표시한다.

```text
2026. 8. 10  방어 실패

김혜은 (4)   ✓      6
김도훈 (3)          3
```

표시 규칙은 다음과 같다.

- 기존 도전자, 방어자 순서로 두 선수를 표시하되 역할 문구는 노출하지 않는다.
- `W`, `L`, `vs`, `도전자`, `방어자`, `OOO 승` 문구를 모두 제거한다.
- 승자 이름 바로 오른쪽에만 원 없는 초록색 체크를 표시한다.
- 선수 이름 바로 뒤에 경기 당시 순위를 괄호로 표시한다. 예: `김혜은 (4)`.
- 순위가 `null`이면 `(–)`를 표시한다.
- 현재 점수 문자열은 `승자점수:패자점수` 형식이다. 콜론 앞 점수를 실제 승자 행에, 콜론 뒤 점수를 실제 패자 행에 배치한다.
- 도전자가 패하고 방어자가 이긴 경기에서도 선수 역할이 아니라 `match.winner`를 기준으로 점수를 매핑한다.
- 날짜 옆의 `방어 성공` 또는 `방어 실패` 문구는 유지한다.
- 숫자 점수는 두 선수 행의 동일한 오른쪽 기준선에 맞춘다.

## 5. 메인 단식 랭킹의 최근 5경기

현재 원형 슬롯 다섯 개와 시간순은 유지하고 원 안의 문자만 아이콘으로 교체한다.

- 승리: 짙은 초록 원 안의 흰색 체크
- 패배: 빨간 원 안의 흰색 X
- 경기 기록이 없는 앞쪽 슬롯: 기존 연회색 빈 원
- `W`와 `L` 문자는 DOM의 표시 텍스트에서 제거한다.
- 각 결과 슬롯에는 `승리` 또는 `패배`라는 접근성 이름과 툴팁을 제공한다.
- 기존 데스크톱·모바일 슬롯 크기와 최근 5경기 정렬을 유지하되 아이콘 선이 뭉치지 않도록 크기를 슬롯보다 작게 설정한다.

## 6. 선수 상세의 최근 경기

각 최근 경기 행의 왼쪽 `W` 또는 `L`을 메인 랭킹과 같은 원형 아이콘으로 교체한다.

- 승리: 짙은 초록 원 안의 흰색 체크
- 패배: 빨간 원 안의 흰색 X
- 상대 이름, 시즌·날짜·역할, 오른쪽의 기존 `6:1` 점수 표시는 유지한다.
- 아이콘을 포함하는 결과 요소에는 `승리` 또는 `패배` 접근성 이름을 제공한다.

전체 경기 기록과 달리 선수 상세는 한 선수 관점의 상대 기록이므로 기존 한 줄 레이아웃과 콜론 점수를 유지한다.

## 7. 반응형·테마 요구사항

- 전체 경기의 선수 이름, 괄호 순위, 승자 체크, 선수별 점수는 390px 화면에서 겹치거나 잘리지 않아야 한다.
- 긴 선수 이름은 점수 열을 밀어내지 않도록 이름 영역에서 말줄임한다.
- 전체 경기의 두 선수 점수는 모바일과 데스크톱 모두 같은 오른쪽 기준선에 놓인다.
- 체크와 X는 16px 이하 슬롯에서도 구분되어야 한다.
- 라이트·다크 모드 모두 승리 초록과 패배 빨강이 배경 및 흰 아이콘과 충분히 대비되어야 한다.
- 빈 최근 경기 슬롯은 다크 모드에서 페이지 배경과 구분되는 회색을 유지한다.
- 아이콘 도입으로 행 높이가 불필요하게 증가하지 않아야 한다.

## 8. 데이터 및 예외 처리

- 표시 전용 변경이며 API 응답과 저장 데이터의 `W`, `L`, `score` 값은 바꾸지 않는다.
- 점수는 현재 저장 계약인 숫자 두 개와 콜론 형식으로 분리한다.
- 예상 형식과 다른 점수가 들어오면 기존 점수 문자열을 경기 항목 오른쪽에 한 번 표시해 결과 정보가 사라지지 않게 한다.
- 승자 이름이 도전자나 방어자와 일치하지 않는 비정상 데이터에서는 승자 체크를 표시하지 않고 기존 선수 순서만 유지한다.

## 9. 테스트와 검수

기능 변경은 TDD로 진행한다.

자동 테스트는 다음을 확인한다.

- 전체 경기 기록에 W/L, 도전자/방어자 역할, `OOO 승`, `vs`가 표시되지 않는다.
- 승자 이름 옆에만 원 없는 체크가 표시된다.
- 도전자 승리와 방어자 승리 각각에서 `승자점수:패자점수`가 실제 선수 행에 올바르게 배치된다.
- 순위는 `(숫자)`로, 순위 없음은 `(–)`로 표시된다.
- 메인 랭킹의 승패 슬롯에 W/L 텍스트 대신 체크·X 아이콘과 한국어 접근성 이름이 표시된다.
- 메인 랭킹의 빈 슬롯 수와 전체 다섯 슬롯 구조가 유지된다.
- 선수 상세의 W/L 텍스트가 같은 체크·X 원형 아이콘으로 교체된다.
- 예상 형식과 다른 점수도 화면에서 사라지지 않는다.
- 관련 기존 정렬, 링크, 선수 상세, 분석 이벤트 테스트가 계속 통과한다.

브라우저에서 서울과기대와 PETC의 다음 조합을 직접 검수한다.

- 데스크톱 라이트
- 데스크톱 다크
- 모바일 라이트
- 모바일 다크

각 조합에서 전체 경기의 도전자 승리·방어자 승리 행, 메인 랭킹의 승·패·빈 슬롯, 선수 상세의 승·패 아이콘을 확인한다.

## 10. 완료 기준

- 사용자에게 보이는 W/L 문자가 세 적용 화면에서 모두 제거된다.
- 전체 경기 기록이 승인된 ATP형 세로 선수·점수 구조와 일치한다.
- 메인 랭킹과 선수 상세가 동일한 원형 체크·X 승패 언어를 사용한다.
- 자동 테스트, 린트, 프로덕션 빌드가 통과한다.
- 모바일·데스크톱, 라이트·다크 브라우저 검수가 완료된다.
- 변경을 논리적인 커밋으로 만들고 원격 `main`에 푸시한다.
