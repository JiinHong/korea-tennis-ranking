# 교내 단식 랭킹 화면 다듬기 및 운영 안내 디자인

## 목적

교내 단식 랭킹의 승패 표현과 선수 정보 정렬을 더 가볍게 다듬고, 전국 랭킹 사용자가 실제 운영 사례와 도입 문의 경로를 자연스럽게 발견하도록 한다.

## 확정된 화면 변경

### 승패 아이콘

- 체크와 X에서 원형 배경을 제거한다.
- 승리는 초록색 체크, 패배는 빨간색 X로 표시한다.
- 기존보다 SVG가 차지하는 비율을 키워 모양을 약간 크게 보이게 한다.
- 빈 최근 경기 슬롯은 기존의 중립색 원형 점을 유지한다.
- 라이트와 다크 모드에서 각각 충분한 대비를 갖는 색을 사용한다.

### 선수 상세

- 라이트 모드처럼 다크 모드에서도 본문 패널과 최근 경기 행의 별도 표면색을 제거한다.
- 구분은 배경 박스가 아니라 가는 구분선과 여백으로만 만든다.
- 헤더 영역의 구조는 유지한다.

### 전체 랭킹 행

- 선수 이름과 최근 경기 날짜를 하나의 정보 묶음으로 취급한다.
- 데스크톱에서는 해당 묶음을 랭킹 행 높이의 중앙에 둔다.
- 모바일 2행 그리드에서는 선수 정보가 두 행을 차지하고 중앙에 오도록 한다.
- 전적과 최근 5경기 아이콘의 현재 오른쪽 정렬은 유지한다.

### 전국 랭킹 운영 안내

- 전국 랭킹 표 바로 아래에 별도의 외곽 박스 없이 안내를 배치한다.
- 제목은 `단식 랭킹 운영 중!`으로 표시한다.
- `PETC 단식 랭킹`과 `느티나무 단식 랭킹` 링크를 각각 제공한다.
- PETC는 고려대학교 마크, 느티나무는 서울과학기술대학교 심벌을 사용한다.
- 로고 주변의 원형 배경은 사용하지 않고 원본 가로세로 비율을 유지한다.
- 모바일에서는 링크를 세로로, 데스크톱에서는 동일 너비의 2열로 배치한다.
- PETC 마크는 라이트 모드에서 원본 검정색, 다크 모드에서 밝은 단색으로 표시한다.
- 서울과학기술대학교 심벌은 두 모드에서 원본 색을 유지한다.
- 마지막 텍스트 링크 `우리 동아리도 운영해보기 →`는 `https://open.kakao.com/o/sFSnlgIi`를 새 창에서 연다.

## 접근성 및 동작

- 두 운영 학교 링크는 `/petc`, `/seoultech`로 이동한다.
- 각 링크의 접근 가능한 이름에 학교/동아리와 `단식 랭킹`을 포함한다.
- 오픈채팅 링크에는 `target="_blank"`와 `rel="noopener noreferrer"`를 사용한다.
- 로고의 대체 텍스트는 링크 이름과 중복되지 않도록 장식 이미지로 처리한다.
- 기존 전국 랭킹 탭, 행 확장, 키보드 포커스 동작은 바꾸지 않는다.

## 검증 기준

- 컴포넌트 테스트가 링크, 문구, 경로, 외부 링크 안전 속성을 검증한다.
- CSS 테스트가 배경 없는 승패 아이콘, 다크모드의 투명한 선수 상세, 선수 묶음 중앙 정렬, 로고 비율과 테마별 필터를 검증한다.
- 모바일과 데스크톱에서 라이트/다크 모드를 직접 확인한다.
- hover 상태에서 흰색 배경이 생기지 않는지 확인한다.
