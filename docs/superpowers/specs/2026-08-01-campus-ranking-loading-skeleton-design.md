# Campus Ranking Loading Skeleton Design

## Goal

캠퍼스 랭킹의 첫 진입 화면이 비어 보이지 않도록, 실제 랭킹 목록의 구조를 암시하는 가벼운 로딩 화면을 제공한다.

## Experience

- 대학 로고와 페이지 제목은 즉시 표시한다.
- 데이터가 준비되기 전에는 선수 수 `0`, 빈 랭킹, 경기 결과 입력 버튼을 노출하지 않는다.
- 로딩 영역에는 `실시간 순위를 불러오고 있어요`와 `잠시만 기다려주세요`를 표시한다.
- 문구 아래에는 순위, 선수 정보, 전적 열을 암시하는 스켈레톤 3줄을 표시한다.
- 스켈레톤은 별도 카드나 외곽 박스 없이 얇은 가로 구분선으로 구성한다.
- 움직임은 은은한 밝기 변화로 제한하며, `prefers-reduced-motion` 환경에서는 애니메이션을 제거한다.

## Accessibility

- 로딩 영역은 기존처럼 `role="status"`와 `aria-live="polite"`를 유지한다.
- 스켈레톤 도형은 정보가 아니므로 보조 기술에서 숨긴다.
- 화면 낭독기는 로딩 제목과 보조 문구만 읽는다.

## Scope

- `ClubRankingClient`의 초기 로딩 상태와 관련 스타일만 변경한다.
- 데이터 요청, 오류 상태, 정상 랭킹 화면의 동작은 변경하지 않는다.
- 새로운 라이브러리나 이미지 에셋을 추가하지 않는다.

## Verification

- 컴포넌트 테스트에서 로딩 문구, 3개의 스켈레톤 행, 숨겨진 실제 콘텐츠를 검증한다.
- 전체 테스트, 린트, 빌드를 실행한다.
- 서울과기대와 PETC를 모바일 및 데스크톱 크기로 확인한다.
