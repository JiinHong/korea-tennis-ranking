# Dark Mode Campus Polish Design

## Goal

캠퍼스 랭킹의 다크모드에서 흐리거나 밝게 튀는 요소를 정리하고, 초기 로딩 애니메이션과 footer 테마 토글을 의도한 형태로 완성한다.

## Theme Behavior And Toggle

- 첫 방문은 운영체제의 라이트·다크 설정을 따른다.
- 토글 UI에는 라이트와 다크 두 상태만 제공한다. 시스템 자동을 별도 선택지로 노출하지 않는다.
- 사용자가 토글을 누르면 현재 해석된 테마의 반대 테마를 명시적으로 저장한다. 이후 방문에서는 저장된 선택을 사용한다.
- 토글은 화면에 고정하지 않고 footer 최하단 행의 오른쪽에 배치한다.
- 토글은 약 `64 × 34px`의 pill 트랙, 이동하는 원형 손잡이, 해·달 아이콘으로 구성한다.
- 모바일에서도 footer 안의 오른쪽에 유지하며 가로 오버플로를 만들지 않는다.
- 버튼은 현재 상태와 다음 동작을 보조 기술에 명확히 전달하고 키보드 초점 표시를 제공한다.

## Campus Header

- 다크모드의 `캠퍼스 랭킹` 라벨은 흐린 회색 대신 밝은 세이지 계열의 글자와 은은한 동색 테두리를 사용한다.
- 라벨은 작은 pill 형태를 유지하되 페이지 제목보다 강조되지 않게 한다.
- PETC의 검정 단색 고려대학교 마크는 다크모드에서 밝은 세이지 계열로 보이도록 변환한다.
- 서울과기대 컬러 로고에는 단색 변환을 적용하지 않는다.
- PETC 마크 처리는 랭킹, 경기 목록, 선수 상세 등 같은 캠퍼스 헤더를 사용하는 화면에 일관되게 적용한다.

## Tournament Update Notice

- `2026 하늘내린인제 결과가 반영됐어요` 영역에만 적용된 다크모드 회색 채움 배경을 제거한다.
- 페이지 배경과 자연스럽게 이어지는 열린 영역으로 유지한다.
- 기존의 얇은 구분선, 붉은 세로 포인트, 제목과 링크의 정보 위계는 유지한다.

## Hover Surfaces

- podium 선수, 최근 30일 기록, 전체 랭킹 행 등 캠퍼스 화면의 hover 배경에 밝은 색을 직접 지정하지 않는다.
- 공통 hover 배경 토큰을 사용해 라이트모드에서는 옅은 강조면, 다크모드에서는 어두운 강조면을 제공한다.
- hover에서도 이름, 순위, 보조 정보의 대비가 유지되어야 한다.
- 캠퍼스 관련 hover 선택자를 함께 점검해 다크모드에서 흰 표면이 나타나는 곳을 남기지 않는다.
- 터치 기기에는 hover 전용 효과를 강제하지 않는다.

## Loading State

- 초기 로딩 화면은 기존 문구, pulse indicator, 3개의 랭킹 skeleton 행 구조를 유지한다.
- 다크모드에서 행 전체를 단색 직사각형으로 채우지 않는다.
- skeleton에는 다크 전용 저·중·고 명암의 그라데이션과 이동하는 shimmer를 사용한다.
- pulse indicator는 어두운 배경에서도 움직임을 알아볼 수 있는 세이지색 대비를 확보한다.
- `prefers-reduced-motion: reduce`에서는 애니메이션을 제거하되 skeleton 구조와 명암은 보이게 한다.

## Scope And Compatibility

- 기존 랭킹 데이터 요청, Supabase 구성, 순위 계산, 경기 입력 로직은 변경하지 않는다.
- 다크모드 수정으로 라이트모드의 기존 정보 구조와 레이아웃이 달라지지 않게 한다.
- 기존 사용자 변경을 되돌리지 않는다.
- 구현은 테스트를 먼저 실패시키는 TDD 순서로 진행한다.

## Verification

- 테마 토글이 최초 시스템 설정을 따르고, 첫 클릭부터 라이트 또는 다크를 저장하는지 컴포넌트 테스트로 확인한다.
- footer 내부 배치, 2단계 pill 구조, 캠퍼스 hover 토큰, PETC 마크 처리, 업데이트 안내의 투명 배경, 다크 skeleton 그라데이션을 회귀 테스트로 고정한다.
- 관련 집중 테스트를 먼저 실행한 뒤 전체 `npm test`, `npm run lint`, `npm run build`를 실행한다.
- 모바일과 데스크톱에서 라이트·다크 모드를 직접 확인한다.
- 캠퍼스 랭킹의 정상 화면과 초기 로딩 화면을 모두 확인하며, hover 가능한 데스크톱 환경에서는 흰 배경 회귀가 없는지 점검한다.
- 검증이 끝난 변경은 커밋하고 `origin/main`에 푸시한다.
