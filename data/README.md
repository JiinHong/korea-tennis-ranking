# data 폴더 안내

애플리케이션이 읽는 검증 완료 원자료를 버전별로 보관합니다.

## 현재 데이터

- `national-ranking/v1/dataset.json`: 전국 대학 테니스 동아리 랭킹의 기준 데이터
- `national-ranking/v1/README.md`: 포함 대회, 출처, 동아리 통합 규칙, 미확정 결과 설명

## 관리 원칙

- 화면에서 보이는 랭킹은 원본 대진표를 직접 읽지 않고 검증된 `dataset.json`을 사용합니다.
- 대회명, 출전명, 동아리 연결, 진출 단계와 출처를 함께 보존합니다.
- 동아리 통합이나 오인식 수정은 근거를 확인한 뒤 보정 스크립트와 테스트에 남깁니다.
- 개인 PC의 절대 경로와 원본 이미지·문서는 저장하지 않습니다. 저장소에는 상대 출처만 기록합니다.
- 데이터 형식이나 계산 의미가 바뀌면 기존 파일을 조용히 덮어쓰기보다 새 버전을 만듭니다.
